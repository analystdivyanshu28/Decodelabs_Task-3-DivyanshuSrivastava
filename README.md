# 🗄️ Week 3 Project – SQL Data Analysis for E-Commerce Sales Dataset

## 📌 Overview

This project was completed during **Week 3** of my **Data Analyst Internship at DecodeLabs**. The objective was to use 
**SQL Server** to analyze an e-commerce sales dataset and extract meaningful business insights 
through querying, aggregation, filtering, and data exploration techniques.

---------------------------------------------------------------------------------------------------------------------------

## 📂 Dataset Information

| Attribute     | Details           |
| ------------- | ----------------- |
| Total Rows    | 1,200             |
| Total Columns | 14                |
| Tool Used     | SQL Server        |
| Analysis Type | SQL Data Analysis |

-----------------------------------------------------------------------------------------------------------------------------

## 🎯 Project Objectives

* Perform data analysis using SQL queries.
* Analyze product performance and revenue generation.
* Evaluate sales trends across different years.
* Assess marketing channel effectiveness.
* Practice SQL aggregation and filtering techniques.

------------------------------------------------------------------------------------------------------------------------------

## 📊 Analysis Performed

### 💰 Sales Performance Analysis

* Calculated total revenue generated.
* Calculated total quantity of products sold.

### 🏆 Product Performance Analysis

* Identified the top-performing products based on:

  * Revenue Generated
  * Quantity Sold

* Identified the lowest-performing products based on:

  * Revenue Generated
  * Quantity Sold

### 📅 Yearly Sales Analysis

* Analyzed yearly revenue trends.
* Compared sales performance across different years.
* Sorted yearly sales data in descending order.

### 📣 Marketing Channel Analysis

* Determined the highest revenue-generating referral source.
* Compared revenue contributions from different marketing channels.

### 📦 Order Status Analysis

* Calculated total orders by status:

  * Delivered
  * Returned
  * Cancelled

### 💳 Customer Purchase Analysis

* Analyzed average quantity ordered.
* Calculated average unit price.

### 🎟️ Coupon Analysis

* Counted the usage frequency of each coupon code.
* Identified the most frequently used promotional coupons.
